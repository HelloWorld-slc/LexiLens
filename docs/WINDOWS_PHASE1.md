# Windows 第一阶段交付记录

日期：2026-10-18；版本：0.1.4。仅实施 Windows 阅读体验。本文补充历史记录，不代表全产品首版验收。

## 设计与使用

沿用原有深浅色与悬浮栏。按用户本轮追加反馈，恢复小图标、悬停/键盘聚焦提示：

- 模式区：划词、短语、句子，互斥且始终显示，选中图标带底线及按下状态。记住最后模式。
- 阅读快捷区：取消、条件出现的解释、收藏、原图、文章/项目总结、总结视图。
- 取消固定占位，空闲置灰；自动解释等待、词句请求、追问、总结和题目请求时提供取消。
- 自动模式：确认正文选区后按原设置延时查询；等待时可“立即解释”，取消或失败后可“解释 / 重试”。成功后不再常驻重复的解释按钮。二次确认模式保留解释/查看解释按钮。
- 更多按固定顺序分组：阅读（原图、文章/项目总结、已存总结、总结视图、多段分析、旧版语境对话）；项目管理（上传与页面、文章组织、导出文章）；偏好与资料（设置、备份与迁移）。高频项同时保留快捷入口；不适用项置灰。

划词及句子模式悬停只预览，点击确认；短语拖动时预览，松手确认并吸附完整词，支持反向选区。保留词内撇号、连字符及短语内标点。只允许同段，纯空白和标点不成为词目标。CSS Highlight 绘制预览和确认选区，不包装或重建正文。离开、滚动、切换模式、文章、项目时清除预览。

全局入口为项目首页、全局生词本、新项目。项目内只展开当前项目，保留折叠及“切换项目”入口；回到项目恢复阅读位置与有效的最后选区。

解释面板使用语境卡片：单词突出本文词性与含义、原句高亮和用法理由；短语突出整体意思和搭配；句子用普通段落呈现原文，依次给译文、关键表达、折叠结构。少量其他常见义来自同一次结构化返回，无数据时不展示、不补一次请求。已有结构对象转为可读文字。发音入口放在对应词句与原句旁。

追问位于独立对话区，基础解释与用户修订不被回复或结构分析替换。用户问题、回复、草稿和失败/取消状态随原库保存。失败重试复用同一消息，重开不自动生成。展示全历史，发送上下文仅取最近六条成功问答。对话以项目、文章、段落、正文版本和精确范围隔离；旧版语境保留并明确标注，可从更多查看。收藏保存基础解释或修订义。

## 兼容与实现

- `src/platform.ts` 以 Windows 平台身份启用新体验，显式排除 Android，不用窗口宽度识别平台。
- `src/desktop-reading.mjs` 管理三种范围、英文句界、可读结构、全历史与有限模型上下文。
- `src/main.ts` 接入桌面交互、导航、分型面板和持久对话；保留现有 Android 路径。
- `src/core.mjs` 扩展选择类型缓存与可选结果校验，兼容旧结果。历史单词及可识别的完整句子按旧字段展示。
- `src/model.ts` 在一次基础解释中请求相应的可选字段；`src/style.css` 使用平台类限定新布局。
- `schema: 1` 不变，对话以兼容的结果条目和锚点保存；既有备份复制能重映射锚点。未复制整套应用。
- 未修改 Android 插件、权限、签名、相机或触摸逻辑；本轮未构建、未验收 Android。

## 本机安装交付

Windows x64 NSIS 0.1.4 已覆盖安装成功（安装器退出码 0，注册版本及可执行文件版本均为 0.1.4）。本轮采用项目现有默认 debug 打包流程，未宣称 release 性能验收。已启动安装目录中的新程序并加载原有资料库，旧文章、历史解释及最终图标栏可读。安装前后原资料库文件 SHA-256 一致；旧程序与资料库只读备份留在本地忽略目录。安装后二进制与构建产物仅相差打包器写入的三字节 NSIS 类型标记。

### 重跑验证

启动 `npm run dev` 后，另一个终端执行 `node scripts/verify-desktop.mjs`。需要本机 Edge 与已安装的开发依赖。夹具位于 `tests/desktop-fixture.html`，使用独立 localStorage 键，不触及安装版 SQLite 或真实 API。输出写入被忽略的 `.local/phase1-evidence/`。

共享与原生逻辑：`./scripts/build.ps1 -Target test`。Windows 安装包：`./scripts/build.ps1 -Target windows`。不要据此运行 Android 构建。

## 边界与未验证项

- 英文句界是保守规则，覆盖常用称谓、缩写、结束引号；非常规省略号、复杂专名缩写仍可能需要人工确认。不是完整语言学断句系统。
- 真实 API 小样本通过不代表所有词义、翻译或教学解释正确。
- 浏览器模拟没有替代原生的全套鼠标边界、窄窗口和故障注入验收；原生本轮重点为真实请求、持久化、收藏和重开。
- TTS 实际声音、系统目录选择、图片重新导入、完整备份 UI、所有网络故障、大型资料库性能未在本轮完整重测。
- Android 完全不构建、不验收；未新增题型、四色证据联动、词库预标或完整长难句教学。
