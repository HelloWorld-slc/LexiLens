# Windows 第二阶段：多题型学案与原文证据联动

日期：2026-10-18；版本：0.1.6 开发测试版。只构建 Windows；没有修改 Android 插件、权限、签名或触摸交互，没有进行 Android 验证。

## 现状核对与实施边界

实施前阅读 README、实施需求基线和交接、第一阶段说明、历史验证以及相关代码；项目和上级目录未找到适用 AGENTS.md。0.1.5 已实现桌面导航、三种选择模式、图标悬浮栏、基础解释与独立聊天。原题仍是 question 段落，由 article-answers 统一请求选择题解答；没有多题型作答状态。本轮保留前者，给文章末尾增加独立学案，不增加常驻工具栏入口。

## 实际支持范围

所有下列深度支持项均接入结构化整理、题目展示、独立作答保存、按需参考解答、讲解和来源校验。识别与讲解依赖模型，真实模型质量本轮未验收。

| 题型 | 实际交互与依据 |
| --- | --- |
| 阅读单选、多选 | 单选按钮 / 多选复选框；保存选项数组。逐项支持、矛盾、未提及、推断或不足说明，字母与颜色并用，可单项或四项 / 全部对照 |
| 完形填空 | 子题自己的选项、空位选择；正文旁空位标记和作答区往返，逐空搭配 / 规则 / 逻辑解释 |
| 选词填空 | 共享词库、每空下拉选择、实际词形输入；使用次数提示；按允许 / 不允许 / 未明确显示重复和变形规则，不统一禁止重复 |
| 语法填空 | 每空独立输入，可有提示词或无提示词；规则与作用空位分开解释 |
| 句子 / 段落补全 | 共享备选句段、多个目标空位、逐空选择及往返定位，支持多于四个选项 |
| 阅读简答 | 较长独立输入、答案要点各自的来源、参考反馈；不按字符串完全相等评分 |
| 词汇英译中 / 中译英 | 明确方向、词汇范围，短输入；语境词义与原文对应表达 |
| 短语英译中 / 中译英 | 明确短语范围，整体表达，短输入；原文表达、调整与其他可接受表达分开 |
| 句子英译中 / 中译英 | 较长译文输入；完整参考译文与关键依据，不扩展成长难句专项分析 |
| 判断、匹配、未知类型 | 标注通用回退；文字作答或目标项与选项对应，保留原文；不宣称具备专项评分规则 |

## 操作方式

1. 在当前文章末尾进入「学案」，点击「整理题目（不解答）」。检查题组、题型和不确定提示后应用；也可手动添加。
2. 用「纠正题目」修改题型、作答方式、题号、题干、选项、要求、翻译方向与范围、空位位置或关联原文。「核对题组 / 归属」修改共享词库和所属文章。换文章后旧关联清除，需重新绑定。
3. 输入即通过现有保存队列保存；左下角只有保存成功才显示已保存。完成状态由学生自己选择。填空点击空号查看原文位置，正文旁的「前往作答」返回；原文文字不会被填入答案。
4. 点击「提示 / 参考答案 / 讲解」才请求这一题的参考帮助。提示先显示，参考答案和完整讲解分别折叠。可以不先作答直接查看。已有有效缓存不重复请求；模型配置、材料和题目版本不同不复用。
5. 翻译参考区分参考答案、原文对应表达、调整、其他可接受表达。「直接采用原文表达」必须与参考答案相同且在正文中真实存在；改写不能这样标注。无对应表达明确提示并提供普通参考译法。
6. 展开选项讲解，点击字母 / 解释定位证据；正文来源标记返回解释。同句多项用多个字母标记，未提及不强配引用。切换题目或文章清除临时来源标记，其他阅读标记不动。
7. 作答后点击「参考反馈」。意义、语法、指定表达要求、措辞差异、可接受与暂不判断分别表达；它不是考试判分。修改答案后需重新请求反馈。
8. 「学习历史」查看历史题组与旧答案、结果摘要，导出完整记录与失败原稿。重整后不静默迁移旧答案到模型新拆分出的题目；人工修改同题新版本会复制草稿并标为待复习。

## 数据与主要文件

- `src/worksheet.mjs`：题型、作答方式、翻译维度、空位、共享选项、引用与输出校验、版本和缓存逻辑。引用使用所属文章、段落、不可变版本及 UTF-16 精确范围；重复片段必须指定起点。只证明文字存在，不证明推理正确。
- `src/worksheet-ui.ts` / `src/worksheet.css`：Windows 学案、编辑表单、独立作答、帮助折叠、词库状态、来源往返、取消与晚到响应隔离。所有外来文字转义后显示。
- `src/main.ts`：在已有文章末尾挂载，沿用导航、窗口与保存队列；仅 Windows 实例化。Windows 文档组织提示扩展到全部练习，Android 原路径不启用。
- `src/model.ts`：识别、参考帮助、参考反馈三个有限任务。错误最多校正一次，保留两次原稿；不在打开材料或题目时自动答题。
- `src/core.mjs`：备份副本额外重映射答案中的选项值与空位键。
- `src-tauri/src/storage.rs`：新增独立学案存储测试，没有修改生产凭据或备份机制。
- `tests/worksheet-fixture.mjs` / `.html`、`tests/worksheet.test.mjs`、`scripts/verify-worksheet.mjs`：可公开合成材料与模拟后端、逻辑和交互回归。

schema 仍为 1。学案、作答、历史与模型尝试是项目的可选扩展字段；旧项目不自动整理，旧 question 段落和 article-answers 结果保留。完整 / 轻量备份仍走原有 SQLite 与资产封装，凭据不进入库或备份。

## 比赛复现与限制

运行 `npm run dev` 后另开终端执行 `node scripts/verify-worksheet.mjs`；需要已安装 Edge。独立 localStorage 键为 phase2-fixture，不访问安装库或真实 API。输出到忽略目录 `.local/phase2-evidence/`。运行 `npm test` 和 `./scripts/build.ps1 -Target test`，Windows 包用 `./scripts/build.ps1 -Target windows`。

可重点观察：整理阶段没有模型答案请求；多选重开仍为两个值；共享词库允许重复时显示次数；中文「参加」对应 takes part in；「她昨天参加了俱乐部」调整为过去式；「太空电梯」明确无原文对应；选项共用一句时出现多个标记，未提及项没有虚构高亮。伪引用、歧义、错版本与跨材料引用由逻辑测试拒绝。合成案例用于验证程序行为，不作为学习提升或模型准确率统计。

已知边界：

- 未归属到任何文章的原始分区仍保留在「非文章部分」。需人工选定文章并添加 / 整理题目；不会默认搜索整个库。无正文的独立学案不是本轮专项入口。
- 手动来源编辑使用段落、精确片段及可选起点；没有增加鼠标圈选关联编辑器。新增空位先保存，再打开表单绑定位置。
- 共享选项超过六个继续保留字母与独立解释，颜色循环；不是任意数量的唯一色谱。
- 参考帮助按单题请求；同组跨题逻辑可利用共享说明和全文，但没有自动生成整套试卷，也没有题组一键批量解答。
- 真实模型语义、复杂 OCR 表格与跨页题目完整性、大型库容量、所有原生网络故障和完整图片导入流程未在本轮穷尽。下一步应在另行授权的真实模型小样本上核对漏题、译文与干扰项解释。
- 没有长难句专项、交互语法树、预测词汇、听说评分、作文批改、自动交卷、账号或云同步。
