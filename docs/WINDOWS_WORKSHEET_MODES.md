# Windows 0.1.8：学案两种模式

2026-10-18；仅 Windows。追加在 [0.1.7 修复记录](WINDOWS_PHASE2_FIXES.md) 之后。

## 操作

文章末尾的「学案」增加模式切换：

- **作答看解析**：默认模式。保留选项、逐空输入、短答/翻译输入、完成状态及参考反馈；提示、参考答案、完整讲解按需展开。「回到我的作答」收起帮助并回到作答控件。
- **直接看答案**：隐藏作答控件和完成状态，保留题目、普通选项、共享词库、空位及来源入口。已有当前版本/模型的参考帮助会直接显示并展开答案；提示与完整讲解仍可按需展开。尚无答案时逐题点击「查看答案 / 解析」，无需先作答。不会自动批量请求答案。「切换到作答」返回对应题目，恢复原来输入。

模式按项目保存在可选字段 worksheetMode 中，缺失时使用作答模式。切换、重开和项目间往返保留设置与原有作答；显示模式不进入模型缓存键，也不修改题目、正文或用户答案。切换时取消进行中的学案请求，晚到响应留作取消记录，不能覆盖当前界面。

## 选项颜色

两种模式下，普通选项文字与边框均为中性样式；选中状态也不采用 A/B/C/D 的证据配色。单独查看提示或答案不启用选项颜色。

展开该题「完整讲解与来源」后，选项字母和左侧边框显示各自稳定配色，解析中的选项与正文证据继续对应；保留字母标记和多选项对照。直接看答案模式下，可点击普通选项定位已展示解析的证据，不改动作答。收起完整讲解后恢复中性选项并移除临时证据标记/高亮；返回作答、切换模式也会清除临时证据。已有学习标记沿用原机制。
