# 0.1.3 开发测试版

- 将逐页 OCR 改为同一个请求中的有序多图转写，再对完整文字进行文章组织和二次检查。
- 统一中文标题，过滤孤立字母伪文章，检查重复正文、漏块、未接合的续句和异常大段；跨页段落合并保留图片来源。
- 已有项目可重新联合整理，核对后替换；旧文章、手改版本与历史整理保留，支持恢复。
- 选择题紧跟所属文章末尾，提供带加载、取消、缓存及原句依据的主动解答。
- 左栏文章归入可折叠“精读”，点击父项串联全部文章与选择题，点击子项单篇阅读。

旧项目需要在“上传与页面”执行“全部图片联合识别”，核对并应用一次，才会获得新的文章组织。原图无需重新上传。

# 0.1.1 开发测试版

本轮集中修复查询反馈、图片导入组织和总结可读性。

- 查词增加等待/加载动画，同一语境复用第一条成功结果；单词下显示词性和简短释义，原句高亮选词，词句发音可直接点击。
- 工具栏改成居中图标栏，按宽度收纳，悬停显示名称；已存总结、设置、备份始终在更多中，全局生词本只保留侧栏入口。
- 桌面拖入图片显示明显添加提示；上传页展示文件、顺序、状态和上/下移动。
- 转写识别文章数量、标题、原文起止块、正文与命名分区；非正文统一进入项目下的“非文章部分”，默认折叠。
- 侧栏增加上传、非文章部分、总结入口；关闭快捷访问不删除资料，首页可重新打开。
- 总结支持当前文章和项目全部两种范围，结果按概览/文章要点/引用显示；兼容常见返回格式，最多一次格式与引用校正；校验未通过时保留可读草稿，不默认展示 JSON。
- 首次缺少 API Key 时显示配置引导；Key 仍只在本机加密保存。
- 两端增加“存储到安装位置”选项：Windows 使用程序旁的 LexiLensData，Android 使用应用内部目录并明确 APK 目录只读、卸载前需导出备份。
- 新项目默认本地日期，空白名称也使用日期；Windows 开发包启动不再显示 CMD 窗口。

旧资料无需重建。已有识别结果沿用原分组；要获取新标题/分区，可以逐页重新识别并核对后作为新文章导入，既有手动编辑不会被覆盖。

本版本仍是开发测试版，Android 真机验收尚未进行。验证细节见 VALIDATION.md。
