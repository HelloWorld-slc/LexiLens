## 再验证命令

```powershell
./scripts/build.ps1 -Target test
./scripts/build.ps1 -Target windows
./scripts/build.ps1 -Target android
```

构建可能受系统安全软件对新编译文件的短时占用影响；已出现新 build-script-build 文件短暂拒绝执行，稍后重试成功。不要通过关闭安全防护处理。

Windows 未启用符号链接权限时，Tauri Android CLI 会在 Rust 编译后停止。可将对应 `.so` 复制到生成工程 `jniLibs` 并跳过对应 Gradle Rust 任务，前提是确认该库由当前源码成功构建。该操作不等于 Android 打包通过。
