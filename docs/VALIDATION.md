# 开发验证记录

日期：2026-09-25。此记录区分编译、独立接口测试与实际设备操作。项目尚未完成首版验收。

## 0.1.3 本轮回归（2026-09-25）

- 查看运行中的旧版窗口，并只读核对当前测试项目：发现 8 个分组，其中一个正文仅为单字母、同一篇文章的跨图续文另成一篇，标题风格混杂。
- 使用该项目的四张有序原图向官方 Flash 接口发送一个多图转写请求，再发送完整文字进行全局文章组织。最终为 6 篇文章、38 个正文自然段、24 道选择题，每篇 4 题；跨图的句中断点被接合在同一自然段中，单字母留在标注分区。标题统一为中文。完整原文块引用、归属唯一性和重复段落检查通过。模型转写仍需人工核对，不能把结构校验当作逐字正确保证。
- 对跨图文章的 4 道题进行真实主动解答测试：4 个答案及引用全部通过正文版本和完整原句定位校验。此测试不代表所有材料答案均准确。
- TypeScript/Vite、37 项 JavaScript 逻辑测试、4 项 Windows Rust 测试通过。新增覆盖整组有序图片负载、重复转写编号整理、漏块/重复归属/选项误入正文拒绝、伪文章保留到其它区、跨页自然段接合、拆分不篡改文字、保守去重、幂等应用、历史恢复、备份副本来源重映射及解答引用校验。
- 隔离浏览器使用共享前端和模拟后端验证：联合识别阶段加载及禁用重复请求，核对后应用，篇末题目、解答加载/可读结果、第二次解答不增加请求。载入本地真实转写结果，确认 6 篇/24 题按“正文—选择题—下一篇”串联；桌面和 390px 手机目录可折叠，手机折叠操作保持目录打开。浏览器测试不代替原生文件与存储全流程。
- Windows x64 NSIS 包 4,433,287 字节，应用 PE subsystem=2（不显示控制台）。Android arm64 APK 43,758,377 字节；在 MuMu Android 15 覆盖安装成功，versionName=0.1.3 / versionCode=1003，冷启动 Status=ok（954ms），进程存活且该进程崩溃日志为空。未进行 Android 真机验收。
- 原图、Key、当前资料库、接口原稿和界面测试夹具仅留本地排除目录，不进入源码仓库。已有项目不自动重写；在“上传与页面”重新联合识别并核对应用，原图可直接复用，旧文章保留在历史整理。

## 0.1.2 本轮回归（2026-09-25）

- TypeScript/Vite 构建、29 项共享逻辑测试、4 项 Windows Rust 测试通过。新增验证 OCR 别名/元数据/空占位块整理、跨两页和三页续接、先后顺序与变更检查、重复应用、备份副本跨页关联重映射、原句排版差异兼容、真正词句错配拒绝、逐段覆盖以及修改后旧摘要失效。
- 真实官方 Flash 接口：两篇文章的 11 个段落返回 11 个独立摘要，全部通过完整原句引用验证。对第二张样图加入第一张的文章结尾作为前页上下文，返回两篇新文章、无错误续接；空题目占位和遗漏的分区辅助元数据已自动整理。真实结果仍存在 OCR 合段、转义排版与印刷细节误差，结构通过不等于文字保真。
- 隔离浏览器中的共享前端（模拟后端、无 Key）：收藏与取消即时同步两处按钮；统一总结菜单和等待界面；三段摘要逐段显示于正文右侧；单词面板和相关工具隐藏，再次切换恢复；模式切换未新增模型请求。1280px 桌面和 390px 手机布局均已目视检查。
- 同一隔离界面验证：首次导入页直接显示两个文件、缩略图、顺序及状态；集中核对后，两页续文变为同一篇、两段正文，左栏只保留一个文章入口。该检查不代替原生数据库/文件导入验收。
- 修复 Vite 在 Windows 构建期间监听 Rust 产物而因文件锁退出的问题；排除原生构建与工具链目录。

0.1.2 最终测试包：Windows x64 NSIS 4,428,635 字节，EXE 的 Windows GUI subsystem=2；Android arm64 APK 43,751,853 字节。最终 APK 在 MuMu Android 15 覆盖安装成功，versionName=0.1.2 / versionCode=1002，冷启动 Status=ok（1103ms），进程存活且未见该进程崩溃日志。真实双页续文样本和 Android 真机操作仍需补充验收。

## 再验证命令

```powershell
./scripts/build.ps1 -Target test
./scripts/build.ps1 -Target windows
./scripts/build.ps1 -Target android
```

构建可能受系统安全软件对新编译文件的短时占用影响；已出现新 build-script-build 文件短暂拒绝执行，稍后重试成功。不要通过关闭安全防护处理。

Windows 未启用符号链接权限时，Tauri Android CLI 会在 Rust 编译后停止。可将对应 `.so` 复制到生成工程 `jniLibs` 并跳过对应 Gradle Rust 任务，前提是确认该库由当前源码成功构建。该操作不等于 Android 打包通过。
