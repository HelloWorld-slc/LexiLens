## 0.1.1 本轮回归（2026-09-25）

- TypeScript/Vite 通过；21 项共享逻辑测试、4 项 Windows Rust 测试通过。新增覆盖同一慢查询不取消/不重复发送、第一条成功缓存重开复用、标题变化不破坏缓存、正文修改失效、日期名称、多文章分区边界、JSON 围栏/字段归一化及格式失败后的可读摘要。
- Windows 原生窗口检查：词性与精简释义出现在选中词下方、原句上方，原句选词高亮，词句发音入口、上传和总结子入口可见。新 EXE 的 PE subsystem 为 Windows GUI（2），开发包也不再申请控制台。
- 在独立浏览器测试页用模拟后端检查共享前端：总结加载界面、项目两篇分开显示、原稿默认折叠、再次点击直接读缓存且请求计数不变；非文章板块默认折叠；关闭快捷访问后首页仍保留项目并可重新打开；查词准备状态、重复点词缓存；390px 窄屏布局和图标工具收纳。测试页不包含 Key，不调用模型，不作为原生存储验收。
- 独立真实 Flash 结构测试：用户授权的三张图分别返回 2 / 2 / 1 篇文章。部分返回缺少描述性标题，补齐标题后通过标题、边界、正文与其它分区完整性校验。仍有手写/印刷归属和段落识别误差，不能把结构通过等同于准确转写，导入前核对仍保留。
- 独立真实项目总结测试：覆盖两篇文章。初次返回有非完整句引用；按同一正文校正一次后，11 个要点的句级引用校验通过，覆盖两篇文章。格式校正不是无限重试，也不自动切换 Pro。
- 图标工具栏固定把已存总结、设置、备份留在更多中，移除工具栏全局生词本入口。实际界面已检查，工具名由悬停/聚焦提示和无障碍标签提供。
- Android 增加应用内部资料目录；APK 安装目录只读，不宣称在 APK 旁写数据库。选择内部目录后，原图和 SQLite 都使用应用内文件；备份另选本机位置导出。SAF 资料库仍沿用此前已确认的外部原图/私有工作库方式。

0.1.1 交付包：Windows x64 NSIS 4,424,077 字节；Android arm64 APK 43,747,861 字节。APK 已在 MuMu Android 15 覆盖安装成功，versionName=0.1.1，冷启动 Status=ok（1715ms），进程存活。完整原生存储/迁移和真机流程仍未由本轮穷尽。

## 再验证命令

```powershell
./scripts/build.ps1 -Target test
./scripts/build.ps1 -Target windows
./scripts/build.ps1 -Target android
```

构建可能受系统安全软件对新编译文件的短时占用影响；已出现新 build-script-build 文件短暂拒绝执行，稍后重试成功。不要通过关闭安全防护处理。

Windows 未启用符号链接权限时，Tauri Android CLI 会在 Rust 编译后停止。可将对应 `.so` 复制到生成工程 `jniLibs` 并跳过对应 Gradle Rust 任务，前提是确认该库由当前源码成功构建。该操作不等于 Android 打包通过。
